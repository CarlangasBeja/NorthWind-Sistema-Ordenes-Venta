NORTHWIND — SOLO ASTRO (INTERFAZ) + ASP.NET CORE (API)

1. Restaura o verifica las bases de datos en (localdb)\MSSQLLocalDB.
2. Configura JWT con Configurar-Desarrollo.ps1 si aún no existe en User Secrets.
3. Para envíos de correo reales configura Resend una vez con Configurar-Resend.ps1 (nunca coloques API Keys en el frontend).
4. Abre PowerShell en la raíz NorthWind. Inicia API:
   dotnet run --project ".\4. Frameworks And Drivers\UI\NorthWind.Sales.WebApi\NorthWind.Sales.WebApi.csproj"
5. Abre otra PowerShell desde NorthWind e inicia Astro:
   cd .\Frontend-Astro
   npm install
   npm run dev
6. Visita http://localhost:4321/login
7. Para comprobar compilación: npm run build (desde Frontend-Astro).

RUTAS: /login  /register  /  /customers  /products  /createorder  /invoices

Si estás actualizando una carpeta vieja por superposición de archivos, ejecuta
Eliminar-Frontend-Anterior.ps1 desde la raíz; primero haz un respaldo.

La API y la base de datos no fueron modificadas.

FEDORA 44: desde la raiz ejecuta  bash INICIAR_FEDORA44.sh  (ver fedora/README_FEDORA44.md).
